# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker Web Application** built using HTML, CSS, and JavaScript.

The application helps users manage their income and expenses and keep track of their overall financial balance.

## 🚀 Features

- 💵 Add Income
- 💸 Add Expenses
- 📊 Calculate Total Income
- 📉 Calculate Total Expenses
- 💰 Display Current Balance
- 📝 Add description for transactions
- 🗑️ Delete transactions
- 💾 Store transaction data using LocalStorage
- 📱 Responsive design
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
